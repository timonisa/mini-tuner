# microtuner

Минималистичный хроматический тюнер для Android. Показывает ближайшую ноту и
отклонение от неё в центах на аналоговой шкале со стрелкой — подходит для
настройки гитары и любых других инструментов.

## Возможности

- Хроматический режим: цель определяется автоматически как ближайшая нота.
- Аналоговая шкала ±25 центов со стрелкой и зоной «в строй» ±5 центов.
- Стабильные показания: медианный фильтр частоты + экспоненциальное сглаживание
  центов; при смене ноты стрелка перестраивается сразу, без «проползания»
  через всю шкалу.
- Регулируемый эталон A4 (430–450 Гц).
- Входной сигнал усиливается на +12 дБ — тихие струны ловятся с большего
  расстояния.
- Темы: светлая (по умолчанию) и тёмная.
- Языки: русский (по умолчанию), English, Español, Deutsch, 中文 — выбор
  в настройках, независимо от языка системы.
- Приватность: аудио обрабатывается только в памяти и нигде не сохраняется
  и не передаётся.

## Как это работает

Высота тона определяется алгоритмом YIN (de Cheveigné & Kawahara, 2002) на
потоке микрофона через `AudioRecord` (44,1 кГц, буферы по ~46 мс). Математика
строя — чистый Kotlin (`core/music`, `core/pitch`), покрыта unit-тестами на
синтетических сигналах. Интерфейс — Jetpack Compose, шкала рисуется на `Canvas`.

## Сборка

Нужен JDK 17 и Android SDK (compileSdk 35, minSdk 24).

```bash
./gradlew test assembleDebug   # тесты + debug APK
```

APK появится в `app/build/outputs/apk/debug/`. Также проект открывается в
Android Studio как обычный Gradle-проект.

> **Windows с кириллическим именем пользователя:** Gradle Test Executor может
> не стартовать из temp-каталога по умолчанию. Обход — задать `TMP`/`TEMP`
> в каталог с ASCII-путём перед сборкой.

## Структура

```
app/src/main/java/com/independentmusictools/tuner/
├── MainActivity.kt            # точка входа, тема и язык приложения
├── audio/AudioCapture.kt      # захват микрофона (+12 дБ входного усиления)
├── core/
│   ├── music/PitchMath.kt     # равномерно-темперированный строй, центы
│   └── pitch/YinPitchDetector.kt
├── settings/TunerSettings.kt  # эталон A4, тема, язык (SharedPreferences)
├── state/TunerViewModel.kt    # сглаживание, статус, состояние UI
└── ui/                        # экран тюнера, настройки, шкала, тема
```

Строки интерфейса — в ресурсах: `values/strings.xml` (русский по умолчанию)
и `values-en`, `values-es`, `values-de`, `values-zh`.

## Тесты

```bash
./gradlew test
```

Unit-тесты проверяют музыкальную математику (частоты стандарта, центы,
ближайшая нота) и детектор YIN на синтетических сигналах.
